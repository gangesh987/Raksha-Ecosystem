# Hackathon Demo Checklist

- Two charged Android devices
- Stable Wi-Fi/mobile network
- Backend reachable over HTTPS/WSS
- TURN configured if direct connectivity is insufficient
- Deployment API token configured securely
- Test accounts/configuration ready
- Camera/microphone permissions granted
- Protection consent prepared
- Backup demo plan clearly labelled `SYNTHETIC DEMO` if used
- Final architecture diagram ready
- Final limitations ready to disclose
