## Live demo

1. Launch Raksha Video on Device A.
2. Launch Raksha Video on Device B.
3. Complete consent and required permissions.
4. Create a call on Device A.
5. Join using the call ID on Device B.
6. Verify real camera and microphone media.
7. Enable Raksha protection with explicit consent.
8. Demonstrate a real conversation.
9. Show a received intelligence/risk event only if the configured intelligence pipeline produces one.
10. Open Safety Center.
11. Demonstrate user-confirmed Safety Brake behavior.
12. Demonstrate trusted-contact workflow only if a real provider is configured.
13. Show structured evidence/timeline.
14. Export evidence if the deployment supports it.
15. End the call and show cleanup.

Never describe a synthetic event as live.
