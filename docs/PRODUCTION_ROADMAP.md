# Production Roadmap

## Phase 1 — current
- authenticated API
- persistent sessions
- explainable baseline risk engine
- WebSocket risk updates
- trusted-contact consent records
- evidence JSON
- audit events
- PostgreSQL-ready deployment

## Phase 2 — Android capture
- Android native permission flow
- foreground service with explicit user consent
- permitted screen/audio capture
- local buffering only
- secure handoff of derived signals

## Phase 3 — real AI
- multilingual ASR
- coercion classifier
- impersonation entity recognition
- visual consistency model
- optional liveness/rPPG
- calibrated fusion model
- benchmark against consented/synthetic datasets

## Phase 4 — trusted response
- push/SMS provider
- verified contact enrollment
- rate limiting
- alert acknowledgement
- incident escalation

## Phase 5 — evidence
- tamper-evident event chain
- encrypted storage
- report templates
- official reporting workflow
- deletion/retention controls

## Phase 6 — production security
- SSO/MFA
- secrets manager/KMS
- WAF
- structured audit trails
- privacy impact assessment
- red-team and abuse testing
