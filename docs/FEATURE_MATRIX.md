# RakshaCall Feature Matrix

| Feature | Prototype status | Production integration |
|---|---|---|
| Live conversation risk | Browser speech recognition + backend fusion | Android on-device ASR + evaluated multilingual NLP |
| On-screen warning | Implemented animated modal + threshold trigger | Native Android overlay/foreground UX |
| Trusted contact | Consent record + prepared alert API | SMS/push provider |
| Evidence report | Structured JSON export | Encrypted/tamper-evident evidence package |
| Visual consistency | Camera permission + supporting UI signal | Evaluated CV model |
| Liveness/rPPG | Supporting signal UI / adapter boundary | Mobile rPPG model + validation |
| Unified risk fusion | 70/20/10 explainable baseline | Calibrated model trained on consented data |
| Authentication | JWT + bcrypt | MFA/device binding/IdP |
| Database | PostgreSQL-ready | Managed PostgreSQL + encryption/KMS |
| Real-time | WebSocket | Scalable event gateway |
| Audit trail | Implemented | Immutable/security SIEM pipeline |

## Product language rules

- Conversation: confident.
- Warning: urgent but calm.
- Trusted contact: consent-forward.
- Evidence: practical/procedural.
- Visual/liveness: modest and hedged.
- Overall: calm, protective, credible.
